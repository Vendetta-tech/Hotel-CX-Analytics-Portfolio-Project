# Hotel CX Analytics Portfolio Project

A portfolio project demonstrating an end-to-end customer experience analytics workflow for a fictional hotel business.

## 🌐 Live Portfolio Website

**[View the live Hotel CX Analytics Portfolio Website →](https://vendetta-tech.github.io/Hotel-CX-Analytics-Portfolio-Project/)**

The responsive website is designed for both desktop and mobile and provides a visual overview of the project, KPIs, insights, recommendations, dataset, SQL report, and case study.

## Objective

Identify the guest and service factors associated with lower satisfaction, analyze recurring experience issues, and translate findings into measurable operational recommendations.

## Project Workflow

1. Business problem definition
2. Data cleaning and validation
3. Exploratory data analysis
4. KPI development
5. Customer segmentation
6. Service issue analysis
7. Dashboard design
8. Recommendations and measurement plan

## Repository Structure

- `data/`: simulated raw and processed datasets
- `sql/`: analytical SQL queries
- `excel/`: Excel analysis guide and deliverables
- `dashboard/`: dashboard specification and screenshots
- `analysis/`: insights and recommendations
- `case-study/`: recruiter-friendly case study
- `assets/`: portfolio visuals

## Key KPIs

Overall Satisfaction, Complaint Rate, Recommendation Rate, Repeat Guest Rate, Average Review Rating, and Resolution Rate.

## Disclaimer

All data in this project is simulated for portfolio demonstration. No findings represent a real hotel company.

## Skills Demonstrated

Excel, SQL, data cleaning, exploratory analysis, KPI design, customer segmentation, dashboard thinking, business recommendations, and stakeholder communication.
