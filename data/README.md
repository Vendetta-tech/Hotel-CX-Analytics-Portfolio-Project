# Data

This project uses a simulated hotel guest experience dataset for portfolio purposes.

Recommended fields include:

- Guest_ID
- Booking_ID
- Stay_Date
- Booking_Channel
- Guest_Type
- Room_Type
- Length_of_Stay
- Check_In_Rating
- Room_Rating
- Cleanliness_Rating
- Staff_Service_Rating
- Food_Beverage_Rating
- Overall_Satisfaction
- Complaint_Flag
- Complaint_Category
- Resolution_Status
- Recommendation_Flag
- Repeat_Guest_Flag

Do not present the dataset as real company data during interviews.
